# Code of Conduct

## Our pledge

We want this project to be a welcoming, professional space for practitioners of every
background and experience level. We pledge to make participation harassment-free for
everyone.

## Expected behavior

- Be respectful and assume good intent.
- Give and accept constructive feedback about the work, not the person.
- Credit others' ideas and sources.
- Keep discussions focused on improving the skills.
- Protect privacy: never post customer, patient or employee data.

## Unacceptable behavior

- Harassment, discrimination, insults or personal attacks.
- Publishing others' private information.
- Spam, self-promotion unrelated to the project, or sustained disruption.

## Enforcement

Maintainers may edit or remove contributions and temporarily or permanently ban contributors
who violate this code. Report concerns privately to the maintainer, Venkat V, using the contact
details on the maintainer's GitHub profile. All reports are reviewed and kept confidential.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).

# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-01

### Added
- `bi-dashboard-design`: level-of-detail tiers, 12-column grid, component library, chart
  selection, theme tokens and the dashboard spec format.
- Platform builders: `powerbi-dashboard-builder` (TMDL, DAX, PBIR),
  `tableau-dashboard-builder` (.tds, calcs, LOD, layout, Tableau Next),
  `looker-dashboard-builder` (LookML views/explores, LookML dashboards).
- Domain skills: `finance-pnl-dashboard`, `finance-ar-collections-dashboard`,
  `finance-ap-spend-dashboard`, `supply-chain-inventory-dashboard`,
  `supply-chain-order-fulfillment-dashboard`, `supply-chain-procurement-dashboard`,
  `healthcare-revenue-cycle-dashboard`, `healthcare-hospital-operations-dashboard`,
  `sales-pipeline-dashboard`, `hr-workforce-dashboard`.
- Installers (`install.sh`, `install.ps1`), Claude Code plugin marketplace manifest,
  validator and catalog generator, CI workflow, contribution templates.
